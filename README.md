# WINDOW/桌面端微信美化

微信调色室是一个 Windows 桌面微信主题编辑器。可以把自己的图片用作整窗壁纸，从整张图提取配色，再分别调整浅色和深色外观。

## 能调整什么

- 整窗壁纸、背景可读性，以及列表和输入区的背景效果。
- 发送和接收气泡、正文、链接、会话选中状态、输入区和界面图标。
- 浅色和深色方案分别编辑。可直接点击工作台预览中的区域，也可进入详细设置。
- 先在微信里试用，确认效果后再部署。支持停用已部署方案和恢复原状。

## 安装与构建

需要 64 位 Windows、.NET Framework、Windows x64 版 Tiny C Compiler（TCC）和 Node.js。实际应用主题只适配 **微信 Windows x64 4.1.15.56 的指定原始构建**。请先确认本机版本，构建脚本会进一步检查 DLL 的 SHA-256 指纹。

1. 下载或克隆仓库，将文件放到自己有写权限的目录。
2. 找到本机微信安装目录下的 `4.1.15.56\Weixin.dll`。如果程序提示指纹不匹配，请检查版本和文件是否已经被其他主题工具修改。
3. 在项目目录打开 PowerShell，把下面两个示例路径换成你的实际路径并执行。

```powershell
.\build.ps1 -Tcc 'C:\tools\tcc\tcc.exe' -WeixinDll 'D:\Weixin\4.1.15.56\Weixin.dll'
```

4. 打开 `dist\WeixinThemeStudio.exe`。使用或移动时请保留整个 `dist` 目录，其中的 `native-runtime` 和 `assets` 是完整构建的一部分。

只想编译编辑器时可以执行 `.\build.ps1`。该命令只生成编辑器，试用和部署需要完整构建。构建脚本从本机微信提取图标资源，供本机使用。仓库只提供源码和构建脚本。

## 怎么使用

1. **选壁纸。** 在工作台点击壁纸区域选择本地图片，检查预览里的裁切和文字可读性。
2. **调配色。** 选中要编辑的浅色或深色方案。可通过「整图取色」生成协调、鲜明或柔和方案，再点击列表、气泡、输入区等区域微调。发送与接收气泡可以分别设置。
3. **试用。** 打开「预览与部署」，按页内编号操作。按提示从系统托盘完全退出微信，再用调色室的测试入口启动。进入微信后应用预览配置，检查聊天列表、收发消息、图标、输入框和通讯录。
4. **部署。** 满意后在流程里确认并保存当前预览方案。按提示完全退出微信、结束试用，再部署已保存方案。部署完成后从桌面的「微信（主题模式）」打开。
5. **停用或恢复。** 在「预览与部署」可停止试用或停用已部署方案。需要完整回退时，先从托盘完全退出微信，再按「启动与恢复」里的恢复原状流程操作。

## 已知问题与反馈

这是测试版。进程内主题通过受控启动加载模块。微信升级后需要重新适配。部分场景曾出现掉帧和通讯录偶发黑底。本次公开源码构建通过，未重新完成微信实机回归。

反馈时请提供 Windows 版本、微信版本、使用的启动入口和复现步骤。可以从调色室导出诊断报告，公开提交前请检查其中的本机路径等信息。

这是独立项目，与腾讯及微信官方无关。
