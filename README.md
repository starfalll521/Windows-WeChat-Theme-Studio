# 微信调色室 · Windows 电脑微信美化

最开始就是想给电脑微信换张自己喜欢的壁纸。后来发现壁纸一换，原来的气泡和文字颜色有时候就看不清了，干脆把这些也做成了能自己调的。

第一次把这个小工具放到 GitHub。想直接试的话，下载下面的 ZIP，解压双击就能开。进去可以先挑张图试试「整图取色」，也可以直接点预览里的气泡、列表和输入框，慢慢调成自己喜欢的样子。浅色和深色可以各存一套。

**[下载微信调色室 8.5 测试版（Windows x64）](https://github.com/starfalll521/Windows-WeChat-Theme-Studio/releases/download/v8.5-beta.1/WeChat-Theme-Studio-Windows-x64.zip)**

目前只适配微信 Windows x64 **4.1.15.56 的指定构建**。版本号一样也可能有不同的安装包，调色室会在应用前检查。

## 第一次打开

解压上面的 ZIP，打开 `WeixinThemeStudio.exe`。请保留旁边的 `native-runtime` 目录。调色室会自动寻找微信，检查正在运行的微信、注册表和常见安装目录，也会记住之前验证过的位置。试用时需要的图标会从本机兼容版本读取。

如果没找到，先正常打开一次微信，再到「启动与恢复」点「重新检测微信位置」。如果还是找不到，再点「手动选择微信位置…」，选本机的 `Weixin.exe` 或 `Weixin.dll`。开始试用前，按页面提示从托盘完全退出微信。

## 换壁纸，调颜色

1. 在工作台点壁纸区域，选一张本地图片。
2. 切到要编辑的浅色或深色方案。想快速配色就点「整图取色」，选协调、鲜明或柔和方案。想微调就直接点画布上的对应区域。
3. 在预览里检查列表文字、收发气泡和链接是否清楚，再到「预览与部署」在微信里看实际效果。

## 在微信里试用和部署

打开「预览与部署」，照着页面上的编号来就行。

1. 点「准备并试启动微信」。按页面提示关闭旧的启动监听，并从托盘完全退出微信。
2. 微信登录并进入主窗口后，点「登录后连接预览」。
3. 点「应用当前配置到微信」。可以回工作台继续调，再应用一次。
4. 看着满意了，点「确认效果并保存方案」。
5. 从托盘退出微信，再点「完成试用（微信已退出）」。
6. 点「部署已确认方案」。以后从桌面的「微信（主题模式）」打开，调色室无需常驻。

## 停用、恢复与反馈

想撤掉主题入口，到「预览与部署」点「停用已部署方案」。想完整恢复，先从托盘退出微信，再到「启动与恢复」点「一键恢复全部原状」。

测试中出现过掉帧和通讯录偶发黑底。遇到问题可以在「预览与部署」点「导出诊断报告…」。反馈时附上微信版本、出问题的步骤和现象，公开分享报告前先检查里面的本机路径。

## 从源码构建

在 Windows PowerShell 中运行 `.\build.ps1` 可以编译编辑器。要完整构建，还需要 Windows x64 版 Tiny C Compiler 和 Node.js。下面的命令里，DLL 路径供构建脚本从本机提取图标资源使用。

```powershell
.\build.ps1 -Tcc 'C:\tools\tcc\tcc.exe' -WeixinDll 'D:\Weixin\4.1.15.56\Weixin.dll'
```

完成后打开 `dist\WeixinThemeStudio.exe`。仓库提供源码和构建脚本，完整构建会在本地生成 `dist\native-runtime` 和 `dist\assets`。

微信调色室是独立项目，与腾讯及微信官方无关。
